## 3. Top 7 for SOFTWARE integration (ranked)
1. Base - best agent-payment/wallet stack (x402 >100M txns, though dollar volume small and wash-trading suspected; AgentKit; gasless; ERC-8004). Pure EVM reuse.
2. Ethereum mainnet - canonical for ERC-8004, Safe/4337/7702 policy modules, best simulation/decoding tooling; the reference chain for permissions/controls. Pure EVM reuse (higher gas; mostly config).
3. Hyperliquid - only candidate directly tied to the product's funding-carry core (perps ~$178B/30d per DefiLlama dashboard; large funding venue). Distinct: own REST/WS API and EIP-712 L1 action signing, agent/API wallets; but a custom adapter, not generic EVM. Highest differentiation. Note HyperEVM exists but trading is via the native API.
4. Solana - highest agent transaction counts (x402 share), large stablecoin/DEX economy; fully distinct stack (ed25519, program accounts, priority fees, Jito, simulation via RPC simulateTransaction). Needs a second adapter; Drift hack shows a permission/approval-control product is relevant.
5. BNB Chain - EVM reuse; large retail/DEX and perp activity, ERC-8004 deployed; cheap add-on after Base. Adds Binance-adjacent user reach and Bybit-style CEX/DeFi bridging.
6. Arbitrum - EVM reuse; deep DeFi/perps (GMX etc.) and funding-relevant venues; low incremental cost, weak agent narrative. Include mostly as config.
7. NEAR - distinct stack (account model, function-call access keys that are a native scoped-permission primitive, Intents >$30B cumulative). Genuinely differentiated for "agent permissions" but smaller economy and higher maintenance. Honorable mention: Tron as READ-ONLY stablecoin balance/monitoring (USDT supply $93.9B), and Bittensor as a watch-only item (Substrate, high maintenance, thin economy, subnet governance risk).

## 4. Reuse vs distinct
- Mostly reuse of one EVM adapter (chain config, RPC, chain id, token list, simulation): Ethereum, Base, Arbitrum, BNB Chain, Polygon, Avalanche. Per-chain work: finality/reorg depth, gas model (L2 data fee), canonical bridge/oracle addresses, ERC-8004/4337 contract deployments.
- Genuinely distinct: Solana (SVM), NEAR (own account/access-key model), Bittensor (Substrate + subnet logic), Hyperliquid native API (off-chain-signed exchange API; HyperEVM is the only EVM part), Sui/TON (Move/TVM), Cosmos, Bitcoin L2s.
